# Basic Informational Site

A small Node.js HTTP server built as part of The Odin Project's Node course.

## Routes

| Path          | Page                  |
| ------------- | --------------------- |
| `/`           | index.html            |
| `/about`      | about.html            |
| `/contact-me` | contact-me.html       |
| anything else | 404.html (status 404) |

## Run locally

```bash
npm install
npm run dev
```
